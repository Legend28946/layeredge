## 🛠️ Setup Instructions

### Prerequisites
- GCC compiler (GNU Compiler Collection)
- Text editor (VS Code, Vim, etc.)
- Terminal/Command line

### Compilation Commands
```bash
# Basic compilation
gcc program.c -o program

# With warnings enabled
gcc -Wall -Wextra program.c -o program

# With debugging information
gcc -g program.c -o program

# Run the program
./program
```

## 🚀 Quick Start

Ready to begin? Let's start with your first C program:

```bash
cd lessons/01_hello_world
gcc hello.c -o hello
./hello
```

## 💡 Tips for Success

1. **Practice Daily** - Even 30 minutes a day makes a huge difference
2. **Type Code Manually** - Don't copy-paste, typing helps you learn
3. **Experiment** - Modify examples and see what happens
4. **Debug** - Learn to read error messages and fix them
5. **Build Projects** - Apply concepts to real problems

## 🆘 Getting Help

- Check the comments in code examples
- Read error messages carefully
- Use `man` command for function documentation
- Search online for C programming resources
